# Kiln

Monorepo for two packages. Each keeps its own version and changelog.

- [`@lchase/kiln`](packages/kiln) — run a workflow on any registered repo. [README](packages/kiln/README.md).
- [`@lchase/yak`](packages/yak) — agentic workflow engine. [README](packages/yak/README.md).

```bash
npm install
npm test
```

Node.js >= 22. `npm i -g @lchase/kiln` still installs the published CLI. Contributing: [packages/kiln/CONTRIBUTING.md](packages/kiln/CONTRIBUTING.md).
