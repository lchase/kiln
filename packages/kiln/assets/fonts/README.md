# Bundled fonts

Roboto and Roboto Mono (latin subset, variable weight), copied from Google Fonts so the Kiln web app looks the same
offline and does not call out to a font host. Both are licensed under the Apache License 2.0
(see `LICENSE-Apache-2.0.txt`). Source: https://fonts.google.com/specimen/Roboto and
https://fonts.google.com/specimen/Roboto+Mono.
